# Brand voice

Use short sentences. Prefer plain words. Run scripts/format.py to tidy the text before you share it.

Use British English. Prefer short words. Read each sentence aloud before you send it.

## Who we are

Acme makes tools for small teams. We are calm, direct and helpful. We never shout, and we never hide the price.

## Tone by channel

| Channel | Tone | Length |
|---|---|---|
| Website | Confident and clear | Short paragraphs |
| Email | Warm and personal | Under 150 words |
| Support reply | Patient and exact | As long as the fix needs |
| Release note | Neutral and factual | One line for each change |
| Social post | Light, never sarcastic | One idea |

## Rules

1. Say "you" and "we". Never "the user" or "the company".
2. Lead with the benefit, then the feature.
3. One idea for each sentence.
4. Use numbers as digits: 3 steps, 5 minutes.
5. Write dates as 3 March 2026.
6. No exclamation marks in support replies.
7. No jargon. If you must use a term, explain it once.
8. Write buttons as verbs: "Save", "Send invoice".
